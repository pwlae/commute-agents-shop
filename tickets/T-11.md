title: Support can't follow an order through the logs
reporter: customer-support
created: 2026-11-20T08:45:00Z

When a customer calls about an order, we copy the trace id from the
gateway log and search all the logs for it. We find it in orders and
in payments, but never in inventory, so we can't tell whether the
stock part worked. This happens for every order we have tried, old
and new.

Example trace id: 7c2e94b1-0d5f-4a83-9e6c-1b48f2a07d35
